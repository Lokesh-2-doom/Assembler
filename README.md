# Simplex Machine Assembler and Emulator

## Overview

This project implements a Simplex Machine system consisting of:

- A **two-pass assembler** (`asm.c`)
- A **stack machine emulator** (`emu.c`)

The assembler converts Simplex assembly programs (`.asm`) into object files (`.obj`).
The emulator loads these object files and executes the generated machine code.

## Compilation

Compile the assembler:

```bash
gcc asm.c -o asm
```

Compile the emulator:

```bash
gcc emu.c -o emu
```

---

## Running the Project

### Step 1: Assemble an Assembly Program

Run:

```bash
./asm tests/test1.asm
```

The assembler generates:

```
test1.obj
test1.lst
```

where:

- `.obj` contains the machine code.
- `.lst` contains the assembly listing.

---

### Step 2: Execute the Object File

Run:

```bash
./emu test1.obj
```

The emulator:

- Loads the object file.
- Executes instructions.
- Displays final register values.
- Creates a memory dump file.

## Notes

- The emulator accepts only `.obj` files generated by the assembler.
- The assembler performs two passes:
  - Pass 1: Builds the symbol table.
  - Pass 2: Generates machine code.
